## 2023-10-25 - [Optimize .first() Queries With Default Ordering] **Learning:** Using `.first()` on a Django model that has a default `ordering` defined in its `Meta` class implicitly adds an `ORDER BY` clause to the SQL query. When performing unique lookups (like by Primary Key or a unique constraint), this `ORDER BY` is completely unnecessary and adds a performance penalty (a sort step) on the database. **Action:** Always add `.order_by()` before `.first()` when you don't actually need the results sorted (especially for unique lookups) to clear the default ordering.
